# NOSMO Nexus Grant Demo

Route: `/grant-demo`

## Purpose

Provide one controlled bilingual presentation path through the working, integrated NOSMO Nexus demonstrator.

## Guided sequence

1. Product and funding overview;
2. Nexus First Run and Work Mode;
3. Fire Door Register & Inspection;
4. DoorFlow plan-led workflow;
5. Electrical Commissioning;
6. Nexus Relationship Tree;
7. Personal InfoCard.

## Presentation claim

Use this wording:

> Integrated functional demonstrator / interactive MVP prototype of the NOSMO Nexus construction work operating system.

## Demonstrated evidence

- one deployable Nexus web build;
- mobile-first entry concept;
- standalone and plan-led fire-door workflows;
- a second specialist trade through Electrical Commissioning;
- project relationship and readiness graph;
- worker identity, qualifications and privacy layer;
- shared navigation between the demonstrations.

## Integrity boundaries

- demonstration data is synthetic or anonymised within the guided routes;
- selected static demonstrations use local browser persistence;
- no production credentials are included;
- no live third-party synchronisation is claimed;
- the Work Mode screen is a PWA/UX demonstrator, not an Android Work Profile;
- the static DoorFlow demo does not include the full production PDF/Excel and backend service stack;
- the demonstrator does not perform regulatory certification.

## Proposed funding scope

- shared production backend and authentication;
- controlled project and person data model;
- PDF/Excel document processing services;
- production evidence storage and audit history;
- approved external connectors;
- native mobile wrapper and Android Work Profile evaluation;
- security, permissions, testing and pilot deployment.

## Review rule

Do not replace or remove the existing Nexus menu or specialist modules. The grant route is an additive presentation layer only.
