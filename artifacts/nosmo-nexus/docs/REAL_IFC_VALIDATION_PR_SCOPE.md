# Real IFC Validation PR Scope

This slice adds validation infrastructure only. It does not import, store or certify real IFC data.

## Added

- product protocol contract;
- compile fixtures;
- validation panel on BIM Object Card;
- manual protocol documentation;
- run template and status tracker.

## Not added

- production IFC storage;
- trusted viewer integration;
- survey validation;
- clash engine;
- FabStation API integration;
- automatic workflow mutation from IFC source data.
