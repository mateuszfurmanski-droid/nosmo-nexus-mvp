# Real IFC Validation Boundary

This boundary is fixed for the BIM / FabStation Operational Layer:

- CI PASS is automated only.
- Real IFC PASS requires representative model evidence.
- Trusted viewer PASS requires manual comparison evidence.
- Full WASM PASS requires real-browser execution evidence.
- Android/Samsung Fold PASS requires device interaction evidence.
- Spatial partner PASS requires partner-confirmed capability evidence.
- No raw IFC, full Psets, meshes, geometry arrays or credentials may be serialized into Project Graph URLs or Change Event envelopes.
